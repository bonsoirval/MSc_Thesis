# Problem Statement

1. Train ensemble model of mobilenet and vision transformer
2. optimize the model using 
    i. pruning
    ii. knowledge distillation
    iii. quantisation
    iv. hyper-parameter tuning
3. Choose best performing optimized model
4. Deploy on mobile

### Success Criteria 
- model accuracy of 80% and above after optimization

### Model Selection Criteria
- A model would be selected based on size and accuracy. 
- Balancing small sie with accuracy
